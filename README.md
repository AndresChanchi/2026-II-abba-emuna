## Estructura

```
README.md                      ← esta página: presentación del proyecto
Docs/
└── Ruta JaveBlockchain/
    ├── team.md                ← integrantes, rol y wallet
    └── gettingStarted.md      ← entorno instalado y hello_world en testnet
```

| Archivo | Qué contiene | Quién lo llena |
|---|---|---|
| [`team.md`](<Docs/Ruta JaveBlockchain/team.md>) | Una fila por integrante: nombre, rol (Emprendimiento o Técnico) y wallet de testnet | Todo el equipo |
| [`gettingStarted.md`](<Docs/Ruta JaveBlockchain/gettingStarted.md>) | Versiones de `rustc` y `stellar`, y el `hello_world` desplegado: Contract ID, enlace y hash del invoke | Integrantes con rol Técnico |

## Cómo usar este ejemplo

1. Crea el repositorio de tu equipo (o haz clic en **Use this template** si está disponible).
2. Copia la carpeta `Docs/Ruta JaveBlockchain/` con sus dos archivos.
3. Reemplaza los datos del Equipo Ejemplo por los de tu equipo.
4. Revisa que no quede ningún `<…>` sin reemplazar antes de abrir el PR.
