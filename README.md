
## Cómo crear el repositorio de tu equipo

1. Arriba en esta página, haz clic en **Use this template → Create a new repository**.
2. **Owner:** `Javeriana-Blockchain`. **Repository name:** `2026-II-<equipo>`, por ejemplo `2026-II-equipo-ejemplo`. **Visibilidad:** Public.
3. Reemplaza los datos del Equipo Ejemplo por los de tu equipo en los tres archivos de `Docs/Ruta JaveBlockchain/`.
4. Revisa que no quede ningún `<…>` sin reemplazar y abre un pull request en el repositorio del equipo.
